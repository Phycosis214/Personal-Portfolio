01 · The basics

Cascading Style Sheet (CSS)

CSS is the language we use to style a Web page.

  • CSS stands for Cascading Style Sheets.
  • CSS describes how HTML elements are to be displayed on screen, paper, or in other media.
  • CSS saves a lot of work — it can control the layout of multiple web pages all at once.
  • External stylesheets are stored in CSS files.
  • CSS defines the design, layout, and variations in display for different devices and screen sizes.
  • CSS definitions are normally saved in an external .css file.
02 · Syntax

CSS Syntax

A CSS rule consists of a selector and a declaration block:

  • The selector points to the HTML element you want to style.
  • The declaration block holds one or more declarations, separated by semicolons.
  • Each declaration has a property name and a value, separated by a colon.
  • Multiple declarations are separated with semicolons; the block is wrapped in curly braces.
p {
  color: red;
  text-align: center;
}
selector property value
03 · Selectors Lab

CSS Selectors

Selectors are used to “find” the HTML elements you want to style — there are five categories. Tap a tab 🎀

p {
  color: red;
  text-align: center;
}
  • element selector — selects HTML elements by tag name.
  • #id selector — selects one unique element using its id, written with a hash (#).
  • .class selector — selects elements with a specific class, written with a period (.).
#para1 {
  color: red;
  text-align: center;
}

.center {
  color: red;
  text-align: center;
}

p.center {
  color: red;
  text-align: center;
}

A combinator defines the relationship between two or more selectors. There are four kinds:

Descendant div p

Selects all elements that are descendants (children, grandchildren…) of a specified element.

Child div > p

Selects all elements that are direct children of a specified element.

Next sibling div + p

Selects the element directly after a specific element (same parent).

Subsequent sibling div ~ p

Selects all elements that are next siblings of a specified element.

Pseudo-classes style an element in a special state, written with a single colon :

I'm a :link
  • Style visited and unvisited links differently
  • Style an element when it gets focus
  • Style valid / invalid / required / optional form elements
  • Style an element that is the first child of its parent

Pseudo-elements style a specific part of an element, written with a double colon ::

  • Style the first letter or first line of an element
  • Insert content before or after an element
  • Style the markers of list items
  • Style the user-selected portion of an element
  • Style the viewbox behind a dialog box
selector::pseudo-element-name {
  CSS properties
}

Attribute selectors style elements based on an attribute or attribute value, wrapped in square brackets [ ].

  • [attribute] — has the specified attribute
  • [attribute="value"] — exact value match
  • [attribute~="value"] — value contains a specific word
  • [attribute|="value"] — value is exact, or starts with value + hyphen
  • [attribute^="value"] — value starts with
  • [attribute$="value"] — value ends with
  • [attribute*="value"] — value contains
04 · Tidy up

CSS Grouping Selector

h1 { text-align: center; color: red; }
h2 { text-align: center; color: red; }
p  { text-align: center; color: red; }
h1, h2, p {
  text-align: center;
  color: red;
}

The grouping selector selects every HTML element that shares the same style. To group selectors, separate each one with a comma — it keeps your code short and sweet. 💛

05 · Getting styles onto the page

How to Add CSS

There are three ways of inserting a style sheet.

Link to an external .css file — change the look of an entire site by editing just one file, using a <link> in the head.

<head>
  <link rel="stylesheet" href="mystyle.css">
</head>

Use the <style> element inside the head section — handy for one page with a unique style.

<style>
  body { background-color: linen; }
  h1 { color: maroon; margin-left: 40px; }
</style>

Add a style attribute directly on an element — great for one-off, unique styling.

<h1 style="color:blue;text-align:center;">Hello</h1>
<p style="color:red;">This is a paragraph.</p>

CSS Fonts

Choosing the right font shapes how readers experience a site. CSS has five generic font families:

Sans-serifArial, Verdana, Helvetica
MonospaceCourier New, Monaco
